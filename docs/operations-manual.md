# 運用保守マニュアル

## デプロイメント

### Vercelへのデプロイ

1. **初期設定**
```bash
# Vercel CLIのインストール
npm i -g vercel

# プロジェクトのリンク
vercel link
```

2. **環境変数の設定**
- Vercelダッシュボードで以下の環境変数を設定：
  ```
  NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME
  CLOUDINARY_API_KEY
  CLOUDINARY_API_SECRET
  CLOUDINARY_FOLDER
  ```

3. **デプロイ実行**
```bash
# プロダクションデプロイ
vercel --prod

# プレビューデプロイ
vercel
```

### ビルドプロセス

1. **ビルド前の確認事項**
   - 環境変数の設定
   - 依存関係の更新
   - TypeScriptのコンパイルエラーチェック

2. **ビルドコマンド**
   ```bash
   npm run build
   ```

3. **ビルド成果物の確認**
   - `.next/`ディレクトリの生成
   - 静的ファイルの最適化
   - ビルドログの確認

## トラブルシューティング

### 一般的な問題と解決方法

1. **画像読み込みエラー**
   ```
   症状：画像が表示されない
   
   確認事項：
   1. Cloudinary認証情報の確認
   2. 画像パスの正確性
   3. ネットワーク接続状態
   
   解決手順：
   1. 環境変数の再確認
   2. Cloudinaryダッシュボードでの画像存在確認
   3. ブラウザキャッシュのクリア
   ```

2. **パフォーマンス低下**
   ```
   症状：ページ読み込みが遅い
   
   確認事項：
   1. 画像サイズと最適化
   2. CDNの応答時間
   3. クライアントサイドのメモリ使用量
   
   解決手順：
   1. 画像最適化設定の確認
   2. キャッシュ戦略の見直し
   3. コンポーネントの最適化
   ```

3. **ビルドエラー**
   ```
   症状：ビルドが失敗する
   
   確認事項：
   1. TypeScriptエラー
   2. 依存関係の競合
   3. 環境変数の不足
   
   解決手順：
   1. tscコマンドでの型チェック
   2. node_modulesの再インストール
   3. .envファイルの確認
   ```
